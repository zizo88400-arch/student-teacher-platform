# منصة الطالب والمعلم — نسخة أولية قابلة للتشغيل

## الموجود في النسخة
- تسجيل حساب طالب أو معلم وتسجيل الدخول والخروج.
- الطالب يختار صفه من أولى إعدادي حتى ثالثة ثانوي، ويرى المحتوى المخصص لصفه.
- المعلم يضيف فيديوهات يوتيوب وروابط وملفات PDF/Word/PowerPoint فيديوهات .
- لوحة مدير لإضافة الأخبار والروابط التعليمية ومشاهدة الحسابات والمحتوى.
- تخزين كلمات المرور بشكل مشفّر باستخدام Werkzeug، وحماية نماذج CSRF.

## التشغيل على الكمبيوتر
1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   ```bash
   python -m venv venv
   ```
   على Windows:
   ```powershell
   venv\\Scripts\\activate
   ```
   على Linux/macOS:
   ```bash
   source venv/bin/activate
   ```
4. ثبّت المكتبات:
   ```bash
   pip install -r requirements.txt
   ```
5. عرّف بيانات المدير قبل أول تشغيل. على PowerShell مثلًا:
   ```powershell
   $env:SECRET_KEY="اكتب-قيمة-سرية-طويلة"
   $env:ADMIN_EMAIL="admin@example.com"
   $env:ADMIN_PASSWORD="كلمة-مرور-قوية-هنا"
   ```
6. شغّل:
   ```bash
   python app.py
   ```
7. افتح في المتصفح: http://127.0.0.1:5000

## ملاحظات مهمة قبل النشر الحقيقي
- هذه نسخة MVP تعليمية وليست منصة إنتاج جاهزة لمئات الآلاف من المستخدمين.
- لا ترفعها على الإنترنت مع `FLASK_DEBUG=1` أو بكلمة السر الافتراضية.
- استخدم HTTPS، وقاعدة PostgreSQL، ونسخًا احتياطية، وحدودًا لمعدل تسجيل الدخول، وفحصًا للملفات المرفوعة، وتخزينًا آمنًا للملفات.
- حاليًا المعلم يستطيع نشر المحتوى مباشرة؛ الأفضل إضافة مراجعة/اعتماد من الإدارة قبل ظهوره للطلاب.
- أضف سياسة خصوصية وشروط استخدام وآلية بلاغات، ولا تجمع بيانات غير ضرورية من الطلاب.
- لا ترفع كتبًا أو مذكرات محمية بحقوق نشر إلا بإذن صاحب الحقوق أو إذا كانت متاحة قانونيًا.
- أخبار الوزارة والمدارس لا تُسحب تلقائيًا؛ المدير يضيف الخبر ورابط مصدره بعد التحقق منه.
- روابط المنصات الخارجية مجرد روابط، ولا تعني وجود شراكة معها.

## هيكل المشروع
- `app.py`: التطبيق وقاعدة البيانات والمسارات.
- `templates/`: صفحات الموقع.
- `static/style.css`: التنسيق.
- `uploads/`: الملفات التي يرفعها المعلمون (ينشأ تلقائيًا).
- `platform.db`: قاعدة SQLite (تنشأ تلقائيًاpsycopg[binary]).
